# 생기부 자동 생성기 (링크판)

학생 소감문을 넣으면 나이스 바이트에 맞춘 생기부(교과세특·자율·동아리·진로·행특) 초안을 써 주는 교사용 웹앱입니다.

- 주소: https://ungcheon-tools.github.io/saenggibu/
- 이 저장소에는 **앱 화면 파일만** 있습니다. 학생 자료·API 키는 없습니다.
- API 키·학생 소감문·결과는 접속한 PC의 브라우저에만 저장되고, AI 요청은 그 PC에서 AI 회사(Gemini·Claude·OpenAI)로 바로 갑니다.
- 원본은 비공개 저장소(saenggibu-generator)에서 만들고 `python build.py` 가 이 폴더의 index.html 을 새로 씁니다. 여기서 직접 고치지 마세요.
- 엑셀판: `생기부_자동_생성기_엑셀판.xlsm` (앱 화면 맨 아래 '엑셀판 받기' 단추가 이 파일을 받아 감. 원본 저장소의 build.py 가 함께 복사)
